Bars are Ergo's difficulty by epoch, from block headers. The outlined bar is the next epoch, computed from block timestamps; dashed while projected. No window can include the next epoch, so windows start 2 epochs out (about 8.5 h from now), in the hatched area. Each epoch is 128 blocks, about 4.3 h.

Order book

Each row is someone's open bet on Ergo's average difficulty over a window of time. Filling one puts you on the other side. Long wins if the window's average ends above the strike, short wins if it ends below. Read how it works for more info.
