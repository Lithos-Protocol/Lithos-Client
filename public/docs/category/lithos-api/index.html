Lithos API

Overview of the Lithos Client API. Lithos provides API calls to view information about mined blocks, miner reward payments, stratum parameters, and collateral utxos. Additionally, authentication allows for miners to create collateral UTXOs which are crucial to continue mining on Lithos. In order to try out API calls, click on a specific request and use the bottom right panel to interact with the client.

API Documentation for the Lithos client. Models used

Stats and participation for the collateral market: the queue, the active set, emission state, and joining

Lithos Dex

Swap, provide liquidity, and collect permanent fees on the LithosDex pool
