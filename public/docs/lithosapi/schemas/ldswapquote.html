LDSwapQuote

Quote for a LithosDex swap

ergInbooleanrequired
Example: true
amountInstringrequired

Total handed to the pool, fees included. Decimal string.

Example: 1000000000
protocolFeestringrequired

Taken out of the input and set aside for liquidity providers. Decimal string.

Example: 1500000
ammFeestringrequired

The curve's own fee on the remainder; stays in the pool. Decimal string.

Example: 1497750
tradedInstringrequired

What actually reaches the curve — amountIn less protocolFee. Decimal string.

Example: 998500000
amountOutstringrequired

What comes back. Decimal string.

Example: 30124883
totalFeestringrequired

Every fee the swap pays, on the input side. Decimal string.

Example: 2997750
spotBeforedoublerequired

Pre-trade price, ignoring fees and depth

Example: 0.0302
spotAfterdoublerequired

Price once the swap lands, ignoring fees

Example: 0.0301
executionPricedoublerequired

Output per unit of input, fees and depth included

Example: 0.0301
priceImpactdoublerequired

How far execution fell short of the pre-trade price, as a fraction

Example: 0.0031
isExecutablebooleanrequired

False when the pool would reject the swap — nothing reaches the curve, or the output would meet or exceed the reserve it is drawn from.

Example: true
