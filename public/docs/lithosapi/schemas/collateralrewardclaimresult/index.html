CollateralRewardClaimResult

Result of claiming unlocked block rewards to the primary address

claims object[]required
  • Array [
    • txIdstringrequired
    Example: 40b7d045a858d537cdbf072e46ffbb86c0c9f6b0e93c369c1ffcba76797636d7
    boxesint32required

    Reward boxes this transaction swept

    Example: 12
    nanoErgsstringrequired

    ERG paid to the primary address by this transaction. Decimal string.

    Example: 36000000000
  • ]
    • claimedNanoErgsstringrequired

    Total ERG across every claim transaction. Decimal string.

    Example: 72000000000
    CollateralRewardClaimResult
    {
      "claims": [

          "txId": "40b7d045a858d537cdbf072e46ffbb86c0c9f6b0e93c369c1ffcba76797636d7",
          "boxes": 12,
          "nanoErgs": "36000000000"
        }
      ],
      "claimedNanoErgs": "72000000000"
    }
