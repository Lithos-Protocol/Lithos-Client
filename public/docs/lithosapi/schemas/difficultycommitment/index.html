DifficultyCommitment

This miner's difficulty commitment.

statestringrequired
  • unregistered: no Miner Dictionary entry; send a commitment to register.
  • registering: a registration was sent and is not yet confirmed and synced.
  • waiting: registered, and the first commitment is not in force yet.
  • active: a commitment is in force.
  • unknown: the commitment could not be read; see reason.

Possible values: [unregistered, registering, waiting, active, unknown]

reasonstring

Why state is unknown or registering.

heightinteger

The chain tip the commitment was read at. Absent when it could not be read.

inForce object

One commitment. Absent when there is none in that slot.

scorestringrequired

The committed score, as an exact decimal string. Payouts are proportional to it.

Possible values: Value must match regular expression ^[0-9]+$

diffstringrequired

score written the way stratum.diff is.

Example: 1.50M
declaredHeightintegerrequired

The height the commitment declares. Super shares count toward it from here.

inForceFromHeightintegerrequired

The first height whose rollups judge NISPs against this commitment.

servedFromHeightinteger

The first block the stratum mines at this score. Present only on a commitment not yet in force.

pending object

One commitment. Absent when there is none in that slot.

scorestringrequired

The committed score, as an exact decimal string. Payouts are proportional to it.

Possible values: Value must match regular expression ^[0-9]+$

diffstringrequired

score written the way stratum.diff is.

Example: 1.50M
declaredHeightintegerrequired

The height the commitment declares. Super shares count toward it from here.

inForceFromHeightintegerrequired

The first height whose rollups judge NISPs against this commitment.

servedFromHeightinteger

The first block the stratum mines at this score. Present only on a commitment not yet in force.

inFlight object

A registration or change that is sent but not yet part of inForce or pending.

txIdstringrequired
kindstringrequired

Possible values: [registration, change]

confirmedHeightinteger

Present once the transaction confirmed, while this client has not yet synced to this height.

commitment objectrequired

One commitment. Absent when there is none in that slot.

scorestringrequired

The committed score, as an exact decimal string. Payouts are proportional to it.

Possible values: Value must match regular expression ^[0-9]+$

diffstringrequired

score written the way stratum.diff is.

Example: 1.50M
declaredHeightintegerrequired

The height the commitment declares. Super shares count toward it from here.

inForceFromHeightintegerrequired

The first height whose rollups judge NISPs against this commitment.

servedFromHeightinteger

The first block the stratum mines at this score. Present only on a commitment not yet in force.

replaceableFromHeightinteger

The first tip a change to the newest commitment can be sent from. Absent while unregistered.

canCommitbooleanrequired

Whether POST /mining/commitment would send now.

blockedReasonstring

Why canCommit is false.

  • TRANSFORMS_DISABLED: state.disableTransforms is on.
  • AUTO_COMMIT: state.autoCommit keeps the commitment at configDiff.
  • UNAVAILABLE: the commitment could not be read.
  • IN_FLIGHT: an earlier registration or change has not settled; see inFlight.
  • SYNCING: the Miner Dictionary is not synced, or the registration is not recorded yet.
  • LOCKED: the newest commitment cannot be replaced before replaceableFromHeight.

Possible values: [TRANSFORMS_DISABLED, AUTO_COMMIT, UNAVAILABLE, IN_FLIGHT, SYNCING, LOCKED]

autoCommitbooleanrequired

Whether state.autoCommit is running and keeps the commitment at configDiff.

configDiffstringrequired

The stratum.diff setting. The stratum serves it until a commitment takes effect, and auto-commit commits it.

Example: 4.0G
timing objectrequired

Blocks from the tip a commitment is sent at.

servedAfterBlocksintegerrequired

Until the stratum mines at a first commitment or a raise. A cut is served once it is in force.

Example: 63
inForceAfterBlocksintegerrequired

Until rollups judge NISPs against it, and this miner can be paid at it.

Example: 125
replaceableAfterBlocksintegerrequired

Until the next change can be sent.

Example: 845
windowBlocksintegerrequired

The blocks a NISP's super shares are drawn from.

Example: 60
rollupLifetimeBlocksintegerrequired

From a rollup opening to its payout.

Example: 720
